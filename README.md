=== Task Management API ===

A RESTful API built with Python and FastAPI to manage tasks and explore core backend development concepts.

=== Overview ===

The Task Management API is a backend application designed to provide task management functionality through REST API endpoints. This project demonstrates practical implementation of API development, database integration, and authentication.

=== Key Features ===

1. User Authentication: User registration and login.
2. JWT Authentication: Token-based authentication for protected endpoints.
3. Task Management: Create, retrieve, update, and delete tasks (CRUD operations).
4. Database Integration: SQLite database with SQLAlchemy.
5. API Documentation: Interactive API documentation using Swagger UI.
  
=== Tech Stack ===

1. Language: Python
2. Framework: FastAPI
3. Database: SQLite
4. ORM: SQLAlchemy
5. Authentication: JWT
  
=== Getting Started ===

1. Clone the repository
git clone https://github.com/AsmaHussain12/Task-Management-API.git
cd Task-Management-API

2. Create a virtual environment
python3 -m venv venv
source venv/bin/activate

3. Install dependencies
Install the packages required by the project.

4. Run the application
uvicorn main:app --reload

5. Explore the API
Open the following URL in your browser after starting the server:
http://127.0.0.1:8000/docs
