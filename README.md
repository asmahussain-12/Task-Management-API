=== Task Management API ===
A RESTful API built with Python and FastAPI to manage tasks and explore core backend development concepts.

=== Overview ===
The Task Management API is a backend application designed to provide task management functionality through REST API endpoints. This project demonstrates practical implementation of API development, database integration, and authentication.

=== Key Features ===
	●	User Authentication: User registration and login.
	●	JWT Authentication: Token-based authentication for protected endpoints.
	●	Task Management: Create, retrieve, update, and delete tasks (CRUD operations).
	●	Database Integration: SQLite database with SQLAlchemy.
	●	API Documentation: Interactive API documentation using Swagger UI.
  
=== Tech Stack ===
	●	Language: Python
	●	Framework: FastAPI
	●	Database: SQLite
	●	ORM: SQLAlchemy
	●	Authentication: JWT
  
=== Getting Started ===
1. Clone the repository
git clone https://github.com/AsmaHussain12/Task-Management-API.git
cd Task-Management-API

2. Create a virtual environment
python3 -m venv venv
source venv/bin/activate

3. Install dependencies
Install the packages required by the project.

4. Run the application
uvicorn main:app --reload

5. Explore the API
Open the following URL in your browser after starting the server:
http://127.0.0.1:8000/docs
